## 部署与维护

- GitHub Pages 发布来源：`main` 分支的 `/docs` 目录。
- 网站为 HTML、CSS 和 JavaScript 静态文件，无构建依赖。
- 内容位于 `docs/posts.json`；更新时必须核对发帖账号、正文、发布时间及原帖链接，并同步修改收集时间。
- 所有资源使用相对路径，适用于 GitHub Pages 的项目网站地址。
- 不要在仓库中保存访问令牌、API 密钥或本机私有配置。
